# Contributing

- Keep this a local, advisory Markdown image-reference review tool. Do not turn unchanged or empty labels into automatic failures.
- Preserve MIT licensing and Deniz Alatas as the author.
- Run `npm test` and `node examples/demo.cjs` after changes. Keep claims tied to tests actually run.
- Keep dependencies pinned and update the lockfile together with package changes.
- Do not commit dependencies, raw test logs, caches, generated archives, credentials, or unrelated files.
- Write short, natural commit messages describing the change. Do not add AI attribution or co-author trailers.
- Publishing a repository, package, or release requires explicit authorization. Keep `private: true` unless npm publication is explicitly requested.
